Getting started

What is VaultTail?

VaultTail is an automatic USB backup app for Windows. Choose the local folders you want to copy and pair a USB drive. With automatic backup enabled and VaultTail running in the background, connecting that drive starts a backup.

How do I automatically back up folders to a USB drive?

Install VaultTail from Microsoft Store, choose your folders, and select your backup drive. Enable automatic backup and Start with Windows. After setup, connect the paired drive to start copying in the background. Check the completion status before removing the drive.

Which Windows versions and drives can I use?

VaultTail supports Windows 10 version 2004 (build 19041) or later, including Windows 11, and external USB drives recognized by Windows. Check the current Microsoft Store listing for the full system requirements and compatibility with your PC.

Can I back up documents, photos, and work folders?

Yes. Select the local folders containing the files you want to copy. Make sure those files are available on your PC and the backup drive has enough free space. Files that exist only online need to be downloaded first.

Do I need a VaultTail account or cloud storage?

No VaultTail account or cloud storage is needed for the local backup workflow. Copies are stored on your paired USB drive. Installation, licensing, and purchases are handled by Microsoft Store.

Automatic backups

Do I need to open the app every time?

No. Enable Start with Windows and leave automatic backup turned on so VaultTail is ready in the background. Closing the main window lets it keep working. If you fully exit VaultTail, open it again before expecting an automatic backup.

Will another USB drive start a backup?

No. VaultTail uses the drive you paired for backup and ignores other USB drives. You can change the selected backup drive in the app.

Does it copy every file again each time?

VaultTail checks your selected folders and copies new or changed files. Unchanged files are skipped, so later backups may have less to copy. Copying time depends on your files and the speed of your PC and USB drive.

Will it move or change my original files?

No. VaultTail copies your selected folders to the paired USB drive. Your original files stay in their original locations, unchanged.

Can it back up while my computer is off or asleep?

Your PC needs to be awake, the drive connected, and VaultTail running to copy files. After waking or restarting your PC, check the backup status before assuming that the latest files have been copied.

What should I check if an automatic backup does not start?

Check that you connected the paired drive, automatic backup is enabled, and VaultTail is running in the background. Confirm that your source folders are available and the USB drive has free space. Review the status shown in the app; contact support if the problem continues.

Your files and recovery

How do I open or restore my backed-up files?

Open your USB drive in File Explorer, then open VaultTail Backup. The copies are ordinary files, so you can browse them or copy them to a folder on your PC without a special restore tool. Restore to a new folder first if you want to avoid replacing files already on your computer.

How can I check that my backup completed?

Review the completion status and any warnings in VaultTail. Open VaultTail Backup on your USB drive and check a few important files. A connected drive alone does not mean that every file finished copying.

What happens if I unplug the drive during a backup?

Copying pauses. Reconnect the same drive and VaultTail can resume from its saved progress. Check the final status and any warnings afterward. Wait for copying to finish and safely eject the drive when possible.

What should I do if the USB drive is full?

Check the available space and the backup status in VaultTail. Free up space carefully or select a larger backup drive, then run the backup again and confirm completion. Do not treat a backup as complete while files are still waiting to be copied.

What if a selected folder is missing or a file is unavailable?

Make the source folder or file available again before backing it up. For example, reconnect a source drive or download an online-only file. Check VaultTail for warnings and confirm that the files you need are present in the completed backup.

Is a USB backup enough to protect all my files?

A USB copy is useful if the original is lost or damaged, but the USB drive itself can fail or be lost. Keep another independent copy of irreplaceable files and disconnect the backup drive after a completed backup when practical. VaultTail copies selected folders; do not treat it as a complete Windows system image.

What happens to my backup if I delete the original file?

The copy already on your USB drive stays there. Deleting a file from your computer does not automatically delete its backup copy during the next backup.

Does VaultTail keep older versions of changed files?

No. On the next backup, an updated file overwrites the previous copy on your USB drive. Older versions are not saved, so VaultTail cannot restore a version that has been overwritten.

Trial, purchase, and support

How does the 14-day trial work?

Get VaultTail from Microsoft Store and try it with your own folders and USB drive for 14 days. Start with a small test folder, run a backup, and open the copied files to check the workflow before buying.

How much does it cost? Is there a subscription?

VaultTail is a one-time purchase with no subscription. Microsoft Store shows the current price in your region, any applicable offer, and the purchase terms before you buy.

Do I need VaultTail to read files I already backed up?

No. Completed backups are ordinary files on your USB drive. You can open and copy them with File Explorer and the usual apps for those file types.
